# 3D Book Reader
Run `node server.js` (no install needed), then open http://localhost:8080 — or the LAN address it prints, from a phone/tablet.
- It auto-detects the newest PDF in this folder, so just replace/edit the PDF. Changes reload automatically, keeping your page.
- Page 1 = front cover, last page = back cover, everything between = paper pages. No page counts are hard-coded.
- `?pdf=name.pdf` picks a specific file; you can also drop/open any PDF from the folder icon.
- Controls: click/tap sides, drag or swipe pages, arrows/Home/End, slider, thumbnails (T), zoom (+/- or pinch), single/double toggle, fullscreen (F).
